# 0013 The mortar-ch org for the mortar.ch tools

**Context:** [GitHub](../core/github.md) lists two kinds of org: one per product with plugins, and
`bitsandbricks-ch` for shared tools and the website. The `mortar-ch` org already exists and holds
the mortar.ch landing page and a repo template; the handbook didn't mention it.

**Decision:** `mortar-ch` is the org for the tools published under mortar.ch and their landing
page. It follows the same rules, settings and rulesets as the other orgs, applied by Mason.

**Consequences:** [GitHub](../core/github.md) lists the org. Which tools move there, and whether
Mason stays in `bitsandbricks-ch`, is decided per tool in its own record.
