# Principles

- **Open source by default.** Apps are for homelabbers, clubs and event crews; code is public unless there is a reason.
- **Privacy.** Public text names the author as "Mike" only. No real hosts, domains, IPs or personal data in repos, screenshots, logs or docs. Use `example.com`, `192.0.2.0/24`, `2001:db8::/32`.
- **Ask, don't guess.** Never make up facts about a project, its users or its author. Leave a `TODO` and ask.
- **Small core, extensible edges.** Features grow as [modules and plugins](../blocks/modules-and-plugins.md).
- **Read-only first.** Anything that changes the outside world starts read-only and gains write abilities one at a time ([security](security.md)).
- **Brand.** Written "BitsAndBricks".

> **Avoiding conflicts:** principles change rarely and only through a PR to this handbook.
