# Rules for coding agents

This repo is the BitsAndBricks handbook itself. Follow [core/git-and-prs.md](core/git-and-prs.md) and [core/ai.md](core/ai.md).

- A rule change says which repos it affects and how they follow (usually `mason sync`).
- Settled questions live in `decisions/`; propose a new record instead of rewriting an old one.
- Keep pages short: rules, then a table or list, then the conflict box.
